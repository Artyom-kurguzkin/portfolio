title: Areas of Expertise
---

- [**Full Stack Web Development**](#filter-Web) designing and implementing graphical user interfaces (Figma, React with Typescript, Power Apps, Blazor), conducting quantitative usability tests; implementing software backend/integration layer (Google Cloud services, Azure services, interfacing with relational databases through SQL or ORMs); implementing simple software delivery pipelines. 

- [**Data Analytics**](#filter-Analytics) proficient in analytical and statistical modeling for static and time-series (signals) datasets; training ML models and estimation algorithms to make predictions and detect anomalies using Python, R, MatLab toolchains; experienced in working with non-structured data sources (non-templated pdf's, image processing). 

- [**Embedded Software Development**](#filter-Electronics) implementing firmware for microcontrollers (PIC, ESP), interfacing with common sensors and actuators; interfacing embedded systems with IT systems (Bluetooth, Wifi, custom UART drivers); designing PCBs for manufacturing (Altium Designer); implementing logic for FPGA devices (VHDL).

- [**Design and Modeling**](#filter-Design) assemblies for 3D printing or CNC Machining: parametric CAD modeling in Autodesk Inventor, mesh surface modeling in Blender, procedural modeling (by interfacing Python with Blender and Inventor APIs).
